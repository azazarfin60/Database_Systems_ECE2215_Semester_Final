# T08.3: Armstrong's Axioms and Additional Inference Rules

> **Topic:** T08 — Normalization & Functional Dependencies | **Priority:** ⭐ High-Yield Candidate | **Exam Frequency:** 0/7 finals (0 marks)
> **Sources:** Silberschatz 7e Ch. 7 (§7.4.1, pp. 320–322) · Lecture Deck 06 (Slides 18–24) · Raidah Class Notes (p. 20)

## Why This Topic Matters

Armstrong's axioms provide the formal inference system used to reason about functional dependencies in relational databases. Although this subtopic has not appeared as an isolated derivation in past semester finals, it forms the theoretical foundation of attribute closures (T08.4), canonical covers (T08.5), and dependency preservation (T08.11). Both RUET lecture slides (Deck 06, Slides 18–24) and student class notes dedicate extensive coverage to these inference rules. Future exams can readily test the statement of these axioms, the concepts of soundness and completeness, or the formal proofs of secondary rules such as Union, Decomposition, and Pseudotransitivity.

---

## 📝 Key Definitions

> **Logically Implied:** "Given a relation schema $r(R)$, a functional dependency $f$ on $R$ is logically implied by a set of functional dependencies $F$ on $R$ if every instance of a relation $r(R)$ that satisfies $F$ also satisfies $f$." — Silberschatz, Korth & Sudarshan, *Database System Concepts* (7th Ed.), §7.4.1 (p. 320)

> **Closure of a Set of Functional Dependencies ($F^+$):** "The closure of $F$, denoted by $F^+$, is the set of all functional dependencies logically implied by $F$." — Silberschatz, Korth & Sudarshan, *Database System Concepts* (7th Ed.), §7.4.1 (p. 321)

> **Soundness and Completeness:** "Armstrong’s axioms are sound, because they do not generate any incorrect functional dependencies. They are complete, because, for a given set $F$ of functional dependencies, they allow us to generate all $F^+$." — Silberschatz, Korth & Sudarshan, *Database System Concepts* (7th Ed.), §7.4.1 (p. 321)

> **Reflexivity Rule:** "If $\alpha$ is a set of attributes and $\beta \subseteq \alpha$, then $\alpha \rightarrow \beta$ holds." — Silberschatz, Korth & Sudarshan, *Database System Concepts* (7th Ed.), §7.4.1 (p. 321)

> **Augmentation Rule:** "If $\alpha \rightarrow \beta$ holds and $\gamma$ is a set of attributes, then $\gamma\alpha \rightarrow \gamma\beta$ holds." — Silberschatz, Korth & Sudarshan, *Database System Concepts* (7th Ed.), §7.4.1 (p. 321)

> **Transitivity Rule:** "If $\alpha \rightarrow \beta$ holds and $\beta \rightarrow \gamma$ holds, then $\alpha \rightarrow \gamma$ holds." — Silberschatz, Korth & Sudarshan, *Database System Concepts* (7th Ed.), §7.4.1 (p. 321)

## Logical Implication and the Need for Axioms

When we design a database table, we start with a given list $F$ of functional dependencies that come directly from real-world rules. However, those starting rules automatically force other hidden dependencies to be true as well. When a new dependency must hold whenever all dependencies in $F$ hold, we say it is **logically implied** by $F$.

For example, consider the schema:

$$
R(A, B, C)
$$

Suppose we know two rules:

$$
A \rightarrow B \quad \text{and} \quad B \rightarrow C
$$

In any valid table, if two rows share the same $A$ value, the first rule forces them to share the same $B$ value. Then, because they share the same $B$ value, the second rule forces them to share the same $C$ value. As a result, $A \rightarrow C$ is automatically true, and the set of all such implied rules is called the **closure** of $F$, written as $F^+$.

Proving implied rules by comparing rows one by one is slow and awkward on large tables. Instead, in 1974, William W. Armstrong gave us three simple symbolic rules (called **Armstrong's axioms**) that let us treat functional dependencies like algebra and derive every possible implied rule in $F^+$.

---

## Armstrong's Three Primary Axioms

Armstrong showed that just three basic rules are enough to find every logically implied functional dependency. In the notation below, Greek letters ($\alpha, \beta, \gamma, \delta$) stand for sets of attributes, and writing two letters side by side like $\alpha\beta$ is shorthand for their union $\alpha \cup \beta$ (so combining $\{A\}$ and $\{B\}$ is written simply as $AB$).

### 1. Reflexivity Rule (Subset Rule)

If $\beta$ is a subset of $\alpha$, then $\alpha$ functionally determines $\beta$:

$$
\text{If } \beta \subseteq \alpha, \text{ then } \alpha \rightarrow \beta
$$

- **Why it works:** If you already know a group of attributes, you obviously know any smaller piece inside that group.
- **Example from Lecture Deck 06 (Slide 18):**

$$
\{\text{Student\_ID}, \text{Name}\} \rightarrow \text{Student\_ID}
$$

  Because $\text{Student\_ID} \subseteq \{\text{Student\_ID}, \text{Name}\}$, this dependency is always true (a trivial dependency).

### 2. Augmentation Rule

If $\alpha \rightarrow \beta$ holds, then attaching the same extra set of attributes $\gamma$ to both sides produces another valid functional dependency:

$$
\text{If } \alpha \rightarrow \beta, \text{ then } \alpha\gamma \rightarrow \beta\gamma
$$

- **Why it works:** If knowing $\alpha$ is enough to uniquely determine $\beta$, then knowing $\alpha$ plus some extra attributes $\gamma$ is certainly enough to determine $\beta$ along with those same extra attributes $\gamma$.
- **Example from Lecture Deck 06 (Slide 19):**
  If:

$$
\text{Student\_ID} \rightarrow \text{Student\_Name}
$$

  Then attaching $\text{Course\_ID}$ to both sides gives:

$$
\{\text{Student\_ID}, \text{Course\_ID}\} \rightarrow \{\text{Student\_Name}, \text{Course\_ID}\}
$$

### 3. Transitivity Rule

If $\alpha$ functionally determines $\beta$, and $\beta$ functionally determines $\gamma$, then $\alpha$ functionally determines $\gamma$:

$$
\text{If } \alpha \rightarrow \beta \text{ and } \beta \rightarrow \gamma, \text{ then } \alpha \rightarrow \gamma
$$

- **Why it works:** Functional dependencies work like a chain of links. If the first set pins down the second, and the second pins down the third, then the first set pins down the third.
- **Example from Lecture Deck 06 (Slide 20):**
  If:

$$
\text{Student\_ID} \rightarrow \text{Dept\_ID} \quad \text{and} \quad \text{Dept\_ID} \rightarrow \text{Department\_Name}
$$

  Then chaining them together gives:

$$
\text{Student\_ID} \rightarrow \text{Department\_Name}
$$

## Soundness and Completeness

Armstrong's axioms have two major theoretical guarantees that make them reliable for database design:

```text
                  ┌──────────────────────────────────────────────┐
                  │            Armstrong's Axioms                │
                  └──────────────────────┬───────────────────────┘
                                         │
                 ┌───────────────────────┴───────────────────────┐
                 ▼                                               ▼
         ┌───────────────┐                               ┌───────────────┐
         │   Soundness   │                               │  Completeness │
         └───────┬───────┘                               └───────┬───────┘
                 │                                               │
                 ▼                                               ▼
   "No false dependencies"                        "No missing dependencies"
   Every derived dependency is                    Every logically implied
   guaranteed to hold in every legal              dependency can be proven
   instance. (100% Correct)                       using these 3 rules. (100% Full)
```

1. **Soundness (Nothing Wrong Is Added):**
   A rule system is sound if every dependency you can derive with it is genuinely true in every valid table that satisfies $F$. In short, the axioms never invent fake rules.
2. **Completeness (Nothing True Is Missed):**
   A rule system is complete if applying the rules repeatedly can generate every single dependency logically implied by $F$. That means the set of rules you can prove with Armstrong's axioms is the exact full closure $F^+$.

## Secondary Inference Rules and Their Formal Proofs

Even though Armstrong's three primary axioms can prove anything in $F^+$, doing every proof with only those three steps can feel like doing multiplication by adding numbers one at a time. To speed up everyday work, we use three handy shortcut rules: **Union**, **Decomposition**, and **Pseudotransitivity**.

Each shortcut rule is proven directly from Armstrong's three primary axioms.

### 1. Union Rule (Additivity)

Intuitively, if $\alpha$ determines $\beta$ and $\alpha$ also determines $\gamma$, we can merge those two arrows into a single rule where $\alpha$ determines both together:

$$
\text{If } \alpha \rightarrow \beta \text{ and } \alpha \rightarrow \gamma, \text{ then } \alpha \rightarrow \beta\gamma
$$

#### Step-by-Step Proof of the Union Rule

1. Start with the first given rule $\alpha \rightarrow \beta$.
   Apply the **Augmentation Rule** by adding $\alpha$ to both sides (remember that $\alpha \cup \alpha = \alpha$):

$$
\alpha\alpha \rightarrow \alpha\beta \implies \alpha \rightarrow \alpha\beta
$$

2. Take the second given rule $\alpha \rightarrow \gamma$.
   Apply the **Augmentation Rule** by adding $\beta$ to both sides:

$$
\alpha\beta \rightarrow \beta\gamma
$$

3. Now chain our two results ($\alpha \rightarrow \alpha\beta$ and $\alpha\beta \rightarrow \beta\gamma$) across the middle term $\alpha\beta$ using the **Transitivity Rule**:

$$
\alpha \rightarrow \beta\gamma
$$

$\blacksquare$ *(Proof complete)*

**Example from Lecture Deck 06 (Slide 21):**
If $\text{Student\_ID} \rightarrow \text{Name}$ and $\text{Student\_ID} \rightarrow \text{Department}$, then we can combine them into:

$$
\text{Student\_ID} \rightarrow \{\text{Name}, \text{Department}\}
$$

---

### 2. Decomposition Rule (Projectivity)

Decomposition is the reverse of the Union rule. If $\alpha$ determines a combined group of attributes on the right-hand side, it also determines each part of that group on its own:

$$
\text{If } \alpha \rightarrow \beta\gamma, \text{ then } \alpha \rightarrow \beta \text{ and } \alpha \rightarrow \gamma
$$

#### Step-by-Step Proof of the Decomposition Rule

1. Look at the right-hand side $\beta\gamma$. Since $\beta$ is a subset of $\beta\gamma$ ($\beta \subseteq \beta\gamma$), the **Reflexivity Rule** tells us:

$$
\beta\gamma \rightarrow \beta
$$

2. We are given $\alpha \rightarrow \beta\gamma$. Chaining $\alpha \rightarrow \beta\gamma$ and $\beta\gamma \rightarrow \beta$ with the **Transitivity Rule** gives:

$$
\alpha \rightarrow \beta
$$

3. By the exact same logic, $\gamma \subseteq \beta\gamma$, so the **Reflexivity Rule** gives:

$$
\beta\gamma \rightarrow \gamma
$$

4. Chaining $\alpha \rightarrow \beta\gamma$ and $\beta\gamma \rightarrow \gamma$ with the **Transitivity Rule** gives:

$$
\alpha \rightarrow \gamma
$$

$\blacksquare$ *(Proof complete)*

**Example from Lecture Deck 06 (Slide 22):**
If $\text{Student\_ID} \rightarrow \{\text{Name}, \text{Department}\}$, then we can split the right side into:

$$
\text{Student\_ID} \rightarrow \text{Name} \quad \text{and} \quad \text{Student\_ID} \rightarrow \text{Department}
$$

> [!WARNING]
> Decomposition works ONLY on the right-hand side (the dependent attributes)! You can NEVER split the left-hand side (the determinant).
> For example, $\{A, B\} \rightarrow C$ (like StudentID and CourseID together determining Grade) does NOT mean $A \rightarrow C$ or $B \rightarrow C$!

---

### 3. Pseudotransitivity Rule

Think of pseudotransitivity as a plug-in substitution rule. If $\alpha$ determines $\beta$, and $\beta$ teams up with $\gamma$ to determine $\delta$, then you can substitute $\alpha$ in place of $\beta$ on the left side:

$$
\text{If } \alpha \rightarrow \beta \text{ and } \gamma\beta \rightarrow \delta, \text{ then } \alpha\gamma \rightarrow \delta
$$

#### Step-by-Step Proof of the Pseudotransitivity Rule

1. Start with the given rule $\alpha \rightarrow \beta$.
   Apply the **Augmentation Rule** by attaching $\gamma$ to both sides:

$$
\alpha\gamma \rightarrow \gamma\beta
$$

2. We are also given $\gamma\beta \rightarrow \delta$.
3. Now chain $\alpha\gamma \rightarrow \gamma\beta$ and $\gamma\beta \rightarrow \delta$ across the common term $\gamma\beta$ using the **Transitivity Rule**:

$$
\alpha\gamma \rightarrow \delta
$$

$\blacksquare$ *(Proof complete)*

**Example from Lecture Deck 06 (Slide 23):**
If:

$$
\text{Student\_ID} \rightarrow \text{Dept\_ID} \quad \text{and} \quad \{\text{Dept\_ID}, \text{Semester}\} \rightarrow \text{Faculty}
$$

Then substituting $\text{Student\_ID}$ for $\text{Dept\_ID}$ gives:

$$
\{\text{Student\_ID}, \text{Semester}\} \rightarrow \text{Faculty}
$$

## Master Summary Table of Inference Rules

The following table summarizes all six rules as presented in Lecture Deck 06 (Slide 24) and Silberschatz 7e (§7.4.1):

| Rule Name | Classification | Formal Statement | Practical Meaning |
| :--- | :--- | :--- | :--- |
| **Reflexivity** | Primary Axiom | If $\beta \subseteq \alpha$, then $\alpha \rightarrow \beta$ | Any attribute set determines its own subsets. |
| **Augmentation** | Primary Axiom | If $\alpha \rightarrow \beta$, then $\alpha\gamma \rightarrow \beta\gamma$ | Adding the same attributes to both sides preserves validity. |
| **Transitivity** | Primary Axiom | If $\alpha \rightarrow \beta$ and $\beta \rightarrow \gamma$, then $\alpha \rightarrow \gamma$ | Dependencies can be chained together sequentially. |
| **Union** | Secondary Rule | If $\alpha \rightarrow \beta$ and $\alpha \rightarrow \gamma$, then $\alpha \rightarrow \beta\gamma$ | Multiple dependencies with the same determinant can be merged. |
| **Decomposition** | Secondary Rule | If $\alpha \rightarrow \beta\gamma$, then $\alpha \rightarrow \beta$ and $\alpha \rightarrow \gamma$ | A composite dependent can be split into individual attributes. |
| **Pseudotransitivity** | Secondary Rule | If $\alpha \rightarrow \beta$ and $\gamma\beta \rightarrow \delta$, then $\alpha\gamma \rightarrow \delta$ | A determinant can substitute for a component in another dependency. |

## Worked Example: Deriving Dependencies Using Axioms

Consider the relation schema:
$$
R(A, B, C, G, H, I)
$$
Given the functional dependency set $F$:
1. $A \rightarrow B$
2. $A \rightarrow C$
3. $CG \rightarrow H$
4. $CG \rightarrow I$
5. $B \rightarrow H$

Let us derive three non-trivial dependencies that belong to $F^+$:

### Derivation 1: Prove $A \rightarrow H$
- From dependency (1), $A \rightarrow B$.
- From dependency (5), $B \rightarrow H$.
- By the **Transitivity Rule**, $A \rightarrow H$ holds.

### Derivation 2: Prove $CG \rightarrow HI$
- From dependency (3), $CG \rightarrow H$.
- From dependency (4), $CG \rightarrow I$.
- By the **Union Rule**, $CG \rightarrow HI$ holds.

### Derivation 3: Prove $AG \rightarrow I$
- From dependency (2), $A \rightarrow C$.
- From dependency (4), $CG \rightarrow I$.
- Notice that $CG$ is $\{C\} \cup \{G\}$.
- By the **Pseudotransitivity Rule** (with $\alpha = A$, $\beta = C$, $\gamma = G$, $\delta = I$):
$$
AG \rightarrow I
$$
- *Alternative derivation using only primary axioms:*
  1. Augment $A \rightarrow C$ with $G$: $AG \rightarrow CG$ (Augmentation).
  2. Combine $AG \rightarrow CG$ with $CG \rightarrow I$: $AG \rightarrow I$ (Transitivity).

## 🔮 Likely Questions

### 🎯 LQ1 · Statement and Explanation of Armstrong's Axioms

> **Predicted Format:** Semester Final Question (4 Marks)

**Question:**

Define Armstrong's axioms. State and explain the three fundamental axioms of functional dependencies with proper examples.

**Full Answer:**

#### Definition
Armstrong's axioms are a set of sound and complete inference rules first proposed by William W. Armstrong in 1974. They are used to test and derive all functional dependencies logically implied by a given set of functional dependencies $F$.

#### The Three Fundamental Axioms

Let $\alpha$, $\beta$, and $\gamma$ denote sets of attributes in a relation schema $R$:

1. **Reflexivity Rule (Subset Rule):**
   If $\beta$ is a subset of $\alpha$, then $\alpha \rightarrow \beta$ always holds:
$$
\text{If } \beta \subseteq \alpha, \text{ then } \alpha \rightarrow \beta
$$
   *Explanation:* A set of attributes uniquely determines its own component values.
   *Example:* In a student database, $\{\text{Roll}, \text{Name}\} \rightarrow \text{Roll}$ is always valid because $\text{Roll} \in \{\text{Roll}, \text{Name}\}$.

2. **Augmentation Rule:**
   If $\alpha \rightarrow \beta$ holds, then adding any attribute set $\gamma$ to both sides preserves the dependency:
$$
\text{If } \alpha \rightarrow \beta, \text{ then } \alpha\gamma \rightarrow \beta\gamma
$$
   *Explanation:* If $\alpha$ uniquely specifies $\beta$, then knowing both $\alpha$ and $\gamma$ uniquely specifies both $\beta$ and $\gamma$.
   *Example:* If $\text{Roll} \rightarrow \text{Name}$, then adding $\text{Dept}$ to both sides yields:
$$
\{\text{Roll}, \text{Dept}\} \rightarrow \{\text{Name}, \text{Dept}\}
$$

3. **Transitivity Rule:**
   If $\alpha$ determines $\beta$, and $\beta$ determines $\gamma$, then $\alpha$ determines $\gamma$:
$$
\text{If } \alpha \rightarrow \beta \text{ and } \beta \rightarrow \gamma, \text{ then } \alpha \rightarrow \gamma
$$
   *Explanation:* Functional determination propagates through intermediate attributes.
   *Example:* If $\text{Roll} \rightarrow \text{Dept\_ID}$ and $\text{Dept\_ID} \rightarrow \text{Dept\_Head}$, then:
$$
\text{Roll} \rightarrow \text{Dept\_Head}
$$

### 🎯 LQ2 · Derivation and Proof of Secondary Inference Rules

> **Predicted Format:** Semester Final Question (5 Marks)

**Question:**

State the Union rule, Decomposition rule, and Pseudotransitivity rule. Prove the Union rule and Decomposition rule using Armstrong's three primary axioms.

**Full Answer:**

#### Statements of Secondary Rules

Let $\alpha, \beta, \gamma, \delta$ be sets of attributes:
- **Union Rule:** If $\alpha \rightarrow \beta$ and $\alpha \rightarrow \gamma$, then $\alpha \rightarrow \beta\gamma$.
- **Decomposition Rule:** If $\alpha \rightarrow \beta\gamma$, then $\alpha \rightarrow \beta$ and $\alpha \rightarrow \gamma$.
- **Pseudotransitivity Rule:** If $\alpha \rightarrow \beta$ and $\gamma\beta \rightarrow \delta$, then $\alpha\gamma \rightarrow \delta$.

---

#### Proof 1: The Union Rule

**Given:**
1. $\alpha \rightarrow \beta$
2. $\alpha \rightarrow \gamma$

**To Prove:**
$$
\alpha \rightarrow \beta\gamma
$$

**Step-by-Step Derivation:**
1. Take the given dependency $\alpha \rightarrow \beta$.
   Augment both sides with $\alpha$ using the **Augmentation Rule**:
$$
\alpha\alpha \rightarrow \alpha\beta \implies \alpha \rightarrow \alpha\beta \quad \text{--- (Step 1)}
$$
2. Take the second given dependency $\alpha \rightarrow \gamma$.
   Augment both sides with $\beta$ using the **Augmentation Rule**:
$$
\alpha\beta \rightarrow \beta\gamma \quad \text{--- (Step 2)}
$$
3. By the **Transitivity Rule**, if $\alpha \rightarrow \alpha\beta$ and $\alpha\beta \rightarrow \beta\gamma$, then:
$$
\alpha \rightarrow \beta\gamma
$$
$\blacksquare$ *(Union rule proven)*

---

#### Proof 2: The Decomposition Rule

**Given:**
$$
\alpha \rightarrow \beta\gamma
$$

**To Prove:**
$$
\alpha \rightarrow \beta \quad \text{and} \quad \alpha \rightarrow \gamma
$$

**Step-by-Step Derivation:**
1. By set theory, the set $\beta$ is a subset of $\beta\gamma$:
$$
\beta \subseteq \beta\gamma
$$
2. By the **Reflexivity Rule**, any set determines its subsets:
$$
\beta\gamma \rightarrow \beta \quad \text{--- (Step 1)}
$$
3. We are given that $\alpha \rightarrow \beta\gamma$.
   Apply the **Transitivity Rule** to $\alpha \rightarrow \beta\gamma$ and $\beta\gamma \rightarrow \beta$:
$$
\alpha \rightarrow \beta
$$
4. Similarly, by set theory, $\gamma \subseteq \beta\gamma$.
   By the **Reflexivity Rule**:
$$
\beta\gamma \rightarrow \gamma \quad \text{--- (Step 2)}
$$
5. Apply the **Transitivity Rule** to $\alpha \rightarrow \beta\gamma$ and $\beta\gamma \rightarrow \gamma$:
$$
\alpha \rightarrow \gamma
$$
$\blacksquare$ *(Decomposition rule proven)*

### 🎯 LQ3 · Soundness and Completeness of Inference Rules

> **Predicted Format:** Semester Final / Class Test Question (3 Marks)

**Question:**

What is meant by the terms "soundness" and "completeness" in the context of Armstrong's axioms? Why do we use secondary rules if Armstrong's axioms are already complete?

**Full Answer:**

#### 1. Soundness
An inference system is **sound** if every functional dependency derived by applying the rules is guaranteed to hold in all legal relation instances satisfying the initial set of dependencies $F$.
- In simple terms: Sound rules never generate incorrect or false functional dependencies.

#### 2. Completeness

An inference system is **complete** if repeated application of the rules can derive every functional dependency that is logically implied by $F$.
- In simple terms: Complete rules can discover every true dependency, so none are missed. The derived set is the exact full closure $F^+$.

#### 3. Why Secondary Rules Are Used
Although Armstrong's three primary axioms (Reflexivity, Augmentation, Transitivity) are mathematically complete, using only those three rules can make derivations long and complicated.
- Secondary rules (Union, Decomposition, and Pseudotransitivity) are shortcuts proven directly from the primary axioms.
- They allow database designers to combine, split, and substitute functional dependencies in fewer steps, accelerating schema normalization and candidate key identification.

## ⚡ Exam Tips & Common Mistakes

1. **Never Decompose the Left-Hand Side:** A frequent exam blunder is splitting determinant attributes. Remember:
$$
\alpha \rightarrow \beta\gamma \implies \alpha \rightarrow \beta \text{ and } \alpha \rightarrow \gamma \quad (\text{Valid decomposition})
$$
$$
\alpha\beta \rightarrow \gamma \centernot\implies \alpha \rightarrow \gamma \text{ or } \beta \rightarrow \gamma \quad (\text{FATAL ERROR})
$$
2. **Cite the Axiom at Every Step:** When writing formal proofs for the Union or Decomposition rules, write the exact name of the axiom used on each line (e.g., "by Augmentation Rule" or "by Reflexivity Rule"). Examiners grade these proofs based on explicit rule citations.
3. **Remember Subset Direction in Reflexivity:** In the Reflexivity Rule, $\beta \subseteq \alpha$ implies $\alpha \rightarrow \beta$. Do not reverse the arrow. The larger set determines the smaller subset, not vice versa.
4. **Use $\beta\gamma$ Instead of $\beta \cup \gamma$:** In standard database notation, attribute set concatenation (e.g., $AC$) denotes union ($A \cup C$). Using standard textbook notation makes your exam paper look polished and professional.
