### Wait-for-Graph Diagram for Q.8(a)

![Fig_2021_Q8.a: Wait-for-graph with 5 transactions T1, T2, T3, T4, T5](diagrams/2021_p02_fig01.jpg)
*Figure 2021_Q8.a — Wait-for-graph for deadlock detection (Source: Page 2, Q.8(a))*

#### Textual & Mathematical Description of Fig_2021_Q8.a (for Visionless LLMs)

1. **Vertices (Transactions):**
   $$V = \{T_1, T_2, T_3, T_4, T_5\}$$

2. **Directed Edges (Wait-for Dependencies):**
   $$E = \{(T_1, T_4), (T_1, T_2), (T_1, T_3), (T_4, T_5), (T_5, T_2), (T_2, T_4)\}$$
   - $T_1 \to T_4$ ($T_1$ waits for $T_4$)
   - $T_1 \to T_2$ ($T_1$ waits for $T_2$)
   - $T_1 \to T_3$ ($T_1$ waits for $T_3$)
   - $T_4 \to T_5$ ($T_4$ waits for $T_5$)
   - $T_5 \to T_2$ ($T_5$ waits for $T_2$)
   - $T_2 \to T_4$ ($T_2$ waits for $T_4$)

3. **Cycle Analysis & Deadlock Detection:**
   - A directed cycle exists among nodes $T_4$, $T_5$, and $T_2$:
     $$T_4 \longrightarrow T_5 \longrightarrow T_2 \longrightarrow T_4$$
   - Since a wait-for-graph contains a deadlock if and only if it has a directed cycle, this schedule contains a **deadlock**.
