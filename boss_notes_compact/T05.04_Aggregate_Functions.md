# T05.04: SQL Aggregate Functions

> **Topic:** T05 · SQL (DDL, DML, Aggregates, Subqueries) | **Priority:** 🟡 | **Exam Frequency:** 2/7 finals (7 marks)
> **Sources:** Silberschatz 7e Ch. 3 (§3.7, pp. 91–98) · Lecture Deck 03 (Slides 30–31) · Classnote by Raidah (p. 2) · Handnote by Fahim (p. 43)

## Aggregate Function Definitions and Principles

**Aggregate Function:** An aggregate function takes a collection (multiset) of values from a column across multiple rows and returns a single summarizing scalar value. SQL provides five primary aggregate functions: `COUNT`, `SUM`, `AVG`, `MIN`, and `MAX`.

**Null Value Handling in Aggregation:** Every aggregate function except `COUNT(*)` ignores `NULL` values in its input multiset. `COUNT(*)` counts all physical tuples matching the selection condition regardless of column nulls.

**Empty Collection Rule:** When applied to an empty table or a column containing only `NULL` values, `COUNT` evaluates to `0`. All other aggregate functions (`SUM`, `AVG`, `MIN`, and `MAX`) evaluate to `NULL`.

---

## The Five Standard Functions

| Function | Mathematical Operation | Supported Data Types | Treatment of Duplicates | Example Statement |
| :--- | :--- | :--- | :--- | :--- |
| `AVG(A)` | Arithmetic mean | Numeric only | Keeps duplicates by default; removes duplicates if `DISTINCT` specified | `SELECT AVG(salary) FROM instructor;` |
| `SUM(A)` | Arithmetic total | Numeric only | Keeps duplicates by default; removes duplicates if `DISTINCT` specified | `SELECT SUM(salary) FROM instructor;` |
| `MIN(A)` | Smallest value | Any ordered type | `DISTINCT` allowed but changes nothing | `SELECT MIN(salary) FROM instructor;` |
| `MAX(A)` | Largest value | Any ordered type | `DISTINCT` allowed but changes nothing | `SELECT MAX(salary) FROM instructor;` |
| `COUNT(A)` | Count of non-null values | Any data type | Counts all non-null entries; counts distinct entries with `DISTINCT` | `SELECT COUNT(ID) FROM instructor;` |
| `COUNT(*)` | Count of total tuples | Whole tuple | Counts every row, including all-null rows | `SELECT COUNT(*) FROM instructor;` |

## Detailed Mechanics

### 1. COUNT Variations
- `COUNT(*)`: Returns total rows passing the `WHERE` condition, including duplicate rows and rows with nulls.
- `COUNT(attribute)`: Evaluates the attribute and returns the number of rows with non-null values.
- `COUNT(DISTINCT attribute)`: Ignores nulls and duplicate values, returning the count of unique values.

```sql
-- Total section offerings in Spring 2018:
SELECT COUNT(*) FROM section WHERE semester = 'Spring' AND year = 2018;

-- Total distinct courses taught in Spring 2018:
SELECT COUNT(DISTINCT course_id) FROM section WHERE semester = 'Spring' AND year = 2018;
```

### 2. Duplicate Retention Rule for SUM and AVG
Aggregate functions must retain duplicate values by default so mathematical totals and means reflect actual data. If three employees earn \$60,000, \$60,000, and \$90,000, the true mean is $\frac{210000}{3} = 70000$. Using `AVG(DISTINCT salary)` discards the duplicate \$60,000 value, distorting the mean to $\frac{150000}{2} = 75000$.

### 3. Non-Numeric Types for MIN and MAX
`MIN` and `MAX` apply to any ordered data type:
- **Numbers:** Evaluates numerical order (`MIN(salary)`).
- **Strings:** Evaluates lexicographical ASCII/Unicode order (`MIN(name)`).
- **Dates and Times:** Evaluates chronological order (`MIN(order_date)` finds the earliest date).

## NULL Value Evaluation Trace

Given an `EMPLOYEE` table with four tuples:

| EID | Name | Salary |
| :--- | :--- | :--- |
| E01 | Alice | 50000 |
| E02 | Bob | NULL |
| E03 | Carol | 70000 |
| E04 | David | NULL |

| Expression | Evaluated Set | Result | Reason |
| :--- | :--- | :---: | :--- |
| `COUNT(*)` | 4 rows | `4` | Counts all physical tuples |
| `COUNT(Salary)` | `{50000, 70000}` | `2` | Skips both NULLs |
| `SUM(Salary)` | $50000 + 70000$ | `120000` | Ignores NULL entries |
| `AVG(Salary)` | $\frac{120000}{2}$ | `60000` | Divides by count of non-null values ($n=2$) |
| `MIN(Salary)` | $\{50000, 70000\}$ | `50000` | Smallest non-null number |
| `MAX(Salary)` | $\{50000, 70000\}$ | `70000` | Largest non-null number |

## Extended Relational Algebra Mapping ($\gamma$)

In relational algebra, SQL aggregation maps to the extended aggregation operator $\gamma$:

$$
{}_{G}\gamma_{F}(E)
$$

Where $G$ represents the optional grouping attributes, $F$ represents aggregate function operations, and $E$ is the input relation.

```sql
SELECT AVG(salary) AS avg_sal
FROM instructor;
```

Maps to:

$$
\gamma_{\text{avg}(\text{salary}) \text{ as } \text{avg\_sal}}(\text{instructor})
$$

## 🏆 Golden Questions (Past Exam Archive)

### 🎯 GQ1 · 2019 Q.8(a) · Four Aggregate Functions · 04 Marks

> *Section B · Asked in: 2019 · L1 (asked once)*

**Question.** Discuss about four aggregate functions.

**Answer.**

An **aggregate function** takes a collection (multiset) of values from a specified attribute and computes a single summarizing scalar value. SQL ignores null values during aggregation (except for `COUNT(*)`).

Four standard aggregate functions:

1. **`COUNT()`:**  
   Computes the number of tuples or non-null attribute values.
   - `COUNT(*)` counts all rows in the relation, including duplicates and nulls.
   - `COUNT(A)` counts non-null values of attribute $A$.
   - *Example:* Count total instructors:

```sql
SELECT COUNT(*) FROM instructor;
```

2. **`SUM()`:**  
   Computes the arithmetic sum of all non-null values in a numeric column.
   - *Example:* Total salary paid to all instructors:

```sql
SELECT SUM(salary) FROM instructor;
```

3. **`AVG()`:**  
   Computes the arithmetic mean of all non-null values in a numeric column.
   - *Example:* Average salary of instructors in the ECE department:

```sql
SELECT AVG(salary) FROM instructor WHERE dept_name = 'ECE';
```

4. **`MIN()` and `MAX()`:**  
   Finds the minimum and maximum values in a column respectively. They operate on numbers, text strings, and dates.
   - *Example:* Lowest and highest salary in the institution:

```sql
SELECT MIN(salary) AS min_sal, MAX(salary) AS max_sal FROM instructor;
```

### 🎯 GQ2 · 2024 Q.7(a) · Definition of Aggregated Functions & Total Department Salary · 03 Marks

> *Section B · CO1 · Asked in: 2024 · L1 (asked once)*

**Question.** Define aggregated functions.  
EMPLOYEE (EID, Name, Department, Salary)  
SALES (SID, EID, SaleAmount, SaleDate)  
The management wants to reward the top-earing department. Write a SQL query to find the total salary paid per department.  
*(Note: "top-earing" printed verbatim in original paper; refers to top-earning)*

**Answer.**

**Definition:** An **aggregate function** is a built-in SQL function that takes a collection of values across a column (or within subsets defined by `GROUP BY`) and returns a single summarizing scalar value. Standard SQL provides five primary aggregate functions: `AVG`, `MIN`, `MAX`, `SUM`, and `COUNT`.

**Query:**

```sql
SELECT Department,
       SUM(Salary) AS Total_Salary
FROM EMPLOYEE
GROUP BY Department;
```

*Note on table selection:* The required attributes `Department` and `Salary` reside entirely in `EMPLOYEE`. The `SALES` relation is an extraneous table that must not be joined. Joining `SALES` would replicate employee salaries for every sale recorded.

## ⚡ Exam Tips & Common Mistakes

- **Avoid Decoy Tables:** In 2024 Q.7(a), joining `SALES` duplicates employee salary rows. Always verify whether the target attributes live inside a single table first.
- **COUNT(\*) vs COUNT(A):** `COUNT(*)` counts rows including NULLs; `COUNT(A)` counts only non-null values of $A$.
- **Empty Table Semantics:** An empty table yields `0` for `COUNT(*)`, but returns `NULL` for `SUM`, `AVG`, `MIN`, and `MAX`.
- **String Types in Aggregates:** Never apply `SUM` or `AVG` to character strings or dates. `MIN` and `MAX` are valid on strings and dates.
- **Alias Outputs:** Always assign meaningful aliases like `AS total_salary` to aggregate output columns.
