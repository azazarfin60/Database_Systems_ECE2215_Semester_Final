# T05.08: SQL Short Notes: ON DELETE CASCADE, GROUP BY, ORDER BY, AS

## 1. ON DELETE CASCADE

**ON DELETE CASCADE:** A foreign key referential integrity clause. When a referenced tuple in a parent relation is deleted, the database automatically deletes all referencing tuples in child relations to prevent orphaned records.

```sql
CREATE TABLE section (
    course_id VARCHAR(8),
    sec_id VARCHAR(8),
    semester VARCHAR(6),
    year NUMERIC(4, 0),
    PRIMARY KEY (course_id, sec_id, semester, year),
    FOREIGN KEY (course_id) REFERENCES course(course_id)
        ON DELETE CASCADE
);
```

### Cascading Mechanics and Alternatives
1. **Multi-Level Cascades:** Deletions can ripple through chains ($A \to B \to C$). Deleting a parent in $A$ triggers deletions in $B$, which in turn triggers deletions in $C$.
2. **Atomic Rollback:** If any step in the cascade violates a constraint, the entire operation is rolled back with no partial deletions.
3. **Alternative Actions:**
   - `ON DELETE RESTRICT` / `NO ACTION` (default): Blocks deletion of the parent tuple if child tuples exist.
   - `ON DELETE SET NULL`: Sets referencing foreign key attributes in child tuples to `NULL`.
   - `ON DELETE SET DEFAULT`: Sets child foreign key attributes to their defined default value.

*(Note: Past papers often print this as "ON CASCADE DELETE". The valid SQL syntax is `ON DELETE CASCADE`.)*

## 2. GROUP BY

**GROUP BY Clause:** An SQL clause that partitions table tuples into distinct groups sharing identical values in specified columns. Aggregate functions (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`) then compute summary metrics for each individual group.

```sql
SELECT dept_name, AVG(salary) AS avg_sal
FROM instructor
GROUP BY dept_name;
```

### Cardinal Rule and Execution Pipeline
1. **Select List Rule:** Any column in `SELECT` outside aggregate functions must appear in `GROUP BY`.
2. **Query Processing Pipeline:**
   `FROM` $\to$ `WHERE` $\to$ `GROUP BY` $\to$ `HAVING` $\to$ `SELECT` $\to$ `ORDER BY`.

## 3. ORDER BY

**ORDER BY Clause:** An SQL clause that sorts query result rows in ascending (`ASC`, default) or descending (`DESC`) order based on one or more attributes. Multiple sort keys break ties sequentially from left to right.

```sql
SELECT name, dept_name, salary
FROM instructor
ORDER BY dept_name ASC, salary DESC;
```

### Key Properties
- **Default Order:** Sorts ascending (`ASC`) from lowest to highest or A to Z.
- **Tie-Breaking:** Evaluates sort keys left to right.
- **Aliases:** Because `ORDER BY` executes after `SELECT`, it can sort on column aliases created in `SELECT`.
- **NULL Handling:** In MySQL, nulls sort first in `ASC` and last in `DESC`.

## 4. AS (Rename Operation)

**AS Clause:** An SQL keyword used to define an alias (an alternative temporary name). It can rename an attribute or computed expression in the `SELECT` clause for readability, or rename a table in the `FROM` clause to shorten table references and enable self-joins.

### 1. Attribute Aliasing
```sql
SELECT salary * 1.15 AS revised_salary,
       COUNT(*) AS total_staff
FROM employee;
```

### 2. Table Aliasing (Tuple Variables)
Assigns a temporary correlation variable to a relation. Essential for self-joins:
```sql
SELECT T.name
FROM instructor AS T, instructor AS S
WHERE T.salary > S.salary AND S.dept_name = 'Comp. Sci.';
```
The keyword `AS` is optional for table aliases (`FROM instructor T`).

ii) Group By

**Question (2019 Q.8(c)).** Write short note on the following statements.  
(i) ON CASCADE DELETE.  
(ii) Group By.

**Question (2023 Q.6(c)).** Write short note on " ON CASCADE DELETE".

**Answer.**

**i) ON DELETE CASCADE (printed as "ON CASCADE DELETE"):**  
A foreign key referential integrity action. When a tuple in the parent table is deleted, the DBMS automatically deletes all corresponding referencing tuples in the child table. This maintains referential integrity and prevents orphaned records.

```sql
CREATE TABLE section (
    course_id VARCHAR(8),
    sec_id VARCHAR(8),
    semester VARCHAR(6),
    year NUMERIC(4, 0),
    PRIMARY KEY (course_id, sec_id, semester, year),
    FOREIGN KEY (course_id) REFERENCES course(course_id)
        ON DELETE CASCADE
);
```

**ii) GROUP BY:**  
An SQL clause used to partition table rows into distinct groups having identical values in specified columns. Aggregate functions (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`) then compute summary statistics for each individual group.

```sql
SELECT dept_name, AVG(salary) AS avg_sal
FROM instructor
GROUP BY dept_name;
```

**iii) ORDER BY:**  
An SQL clause that sorts query result rows in ascending (`ASC`, default) or descending (`DESC`) order based on one or more attributes. Multiple sort keys break ties sequentially.

```sql
SELECT name, salary
FROM instructor
ORDER BY salary DESC, name ASC;
```

**iv) AS:**  
An SQL keyword used to define an alias (an alternative temporary name). It can rename an attribute or computed expression in the `SELECT` clause for readability, or rename a table in the `FROM` clause to shorten table references and enable self-joins.

```sql
SELECT salary * 1.15 AS revised_salary
FROM employee AS e;
```

*Short version for 2023 Q.6(c) (2 marks):* Provide part (i) with definition, syntax, and effect.

## ⚡ Exam Tips & Common Mistakes

- **Syntax Name:** The valid SQL clause is `ON DELETE CASCADE`. Mention the prompt label "ON CASCADE DELETE", but write `ON DELETE CASCADE` in code snippets.
- **Always Include SQL Snippets:** Even for 1-mark notes, write a 3-line SQL example with correct keywords.
- **Unaggregated Column Rule:** Never select an unaggregated attribute that is absent from `GROUP BY`.
- **Scope of AS Aliases:** Remember that column aliases created in `SELECT` cannot be referenced in `WHERE` because `WHERE` runs first.
