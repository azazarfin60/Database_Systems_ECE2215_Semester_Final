## Logical Implication and Armstrong's Axioms

A database designer starts with an initial set $F$ of functional dependencies. These base rules automatically force other dependencies to hold.

**Logically Implied:** A functional dependency $f$ is logically implied by $F$ if every legal relation instance satisfying all dependencies in $F$ also satisfies $f$.

**Closure of a Set of Functional Dependencies ($F^+$):** The complete set of all functional dependencies logically implied by $F$.

**Armstrong's Axioms:** A set of three foundational inference rules published by William W. Armstrong in 1974. They provide a sound and complete system to derive every implied functional dependency in $F^+$.

### The Three Primary Axioms

Let $\alpha, \beta, \gamma$ denote attribute sets. Juxtaposition ($\alpha\beta$) denotes union ($\alpha \cup \beta$).

1. **Reflexivity Rule (Subset Rule):**
   If $\beta \subseteq \alpha$, then $\alpha \rightarrow \beta$ holds.
   - Any attribute set functionally determines its own subsets (trivial FDs).
   - Example: $\{\text{StudentID}, \text{Name}\} \rightarrow \text{StudentID}$.

2. **Augmentation Rule:**
   If $\alpha \rightarrow \beta$, then $\alpha\gamma \rightarrow \beta\gamma$ holds for any attribute set $\gamma$.
   - Adding identical attributes to both sides preserves the dependency.
   - Example: If $\text{StudentID} \rightarrow \text{Name}$, then $\{\text{StudentID}, \text{CourseID}\} \rightarrow \{\text{Name}, \text{CourseID}\}$.

3. **Transitivity Rule:**
   If $\alpha \rightarrow \beta$ and $\beta \rightarrow \gamma$, then $\alpha \rightarrow \gamma$ holds.
   - Functional dependencies can be chained sequentially.
   - Example: If $\text{StudentID} \rightarrow \text{DeptID}$ and $\text{DeptID} \rightarrow \text{DeptName}$, then $\text{StudentID} \rightarrow \text{DeptName}$.

### Soundness and Completeness

**Soundness and Completeness:** A set of inference rules is sound if it derives only valid functional dependencies logically implied by $F$, and complete if it can derive all functional dependencies logically implied by $F$.

- **Soundness:** The axioms generate only correct dependencies. Every dependency derived using these rules is guaranteed to hold in every legal relation instance ($F \vdash f \implies f \in F^+$). No false rules are generated.
- **Completeness:** The axioms generate all valid dependencies. Any dependency that is logically implied by $F$ can be derived using only these three rules ($f \in F^+ \implies F \vdash f$). No valid rules are missed.

## Secondary Inference Rules

Three derived shortcut rules simplify algebraic derivations:

1. **Union Rule (Additivity):**
   If $\alpha \rightarrow \beta$ and $\alpha \rightarrow \gamma$, then $\alpha \rightarrow \beta\gamma$.

2. **Decomposition Rule (Projectivity):**
   If $\alpha \rightarrow \beta\gamma$, then $\alpha \rightarrow \beta$ and $\alpha \rightarrow \gamma$.

3. **Pseudotransitivity Rule:**
   If $\alpha \rightarrow \beta$ and $\gamma\beta \rightarrow \delta$, then $\alpha\gamma \rightarrow \delta$.

### Master Summary of Inference Rules

| Rule Name | Class | Formal Statement | Practical Meaning |
| :--- | :--- | :--- | :--- |
| **Reflexivity** | Primary | If $\beta \subseteq \alpha$, then $\alpha \rightarrow \beta$ | A set determines its own subsets. |
| **Augmentation** | Primary | If $\alpha \rightarrow \beta$, then $\alpha\gamma \rightarrow \beta\gamma$ | Adding attributes to both sides preserves validity. |
| **Transitivity** | Primary | If $\alpha \rightarrow \beta$ and $\beta \rightarrow \gamma$, then $\alpha \rightarrow \gamma$ | Dependencies chain together. |
| **Union** | Secondary | If $\alpha \rightarrow \beta$ and $\alpha \rightarrow \gamma$, then $\alpha \rightarrow \beta\gamma$ | Common determinants combine dependents. |
| **Decomposition** | Secondary | If $\alpha \rightarrow \beta\gamma$, then $\alpha \rightarrow \beta$ and $\alpha \rightarrow \gamma$ | Dependents can be split individually. |
| **Pseudotransitivity** | Secondary | If $\alpha \rightarrow \beta$ and $\gamma\beta \rightarrow \delta$, then $\alpha\gamma \rightarrow \delta$ | Determinant substitutes into another dependency. |

## 🔮 Likely Questions

### 🎯 LQ1 · Armstrong's Axioms, Soundness, and Completeness · 04 Marks

> *Section A / B · Probability: High (Unasked topic with extensive slide and note coverage)*

**Question.** State Armstrong's three primary axioms for functional dependencies. Explain what is meant by soundness and completeness.

**Answer.**

#### 1. Armstrong's Three Primary Axioms

Let $\alpha, \beta, \gamma$ be sets of attributes in relation schema $R$:

1. **Reflexivity Rule:**  
   If $\beta \subseteq \alpha$, then $\alpha \rightarrow \beta$.  
   *Example:* $\{A, B\} \rightarrow A$.
2. **Augmentation Rule:**  
   If $\alpha \rightarrow \beta$, then $\alpha\gamma \rightarrow \beta\gamma$ for any attribute set $\gamma$.  
   *Example:* If $A \rightarrow B$, then $AC \rightarrow BC$.
3. **Transitivity Rule:**  
   If $\alpha \rightarrow \beta$ and $\beta \rightarrow \gamma$, then $\alpha \rightarrow \gamma$.  
   *Example:* If $A \rightarrow B$ and $B \rightarrow C$, then $A \rightarrow C$.

#### 2. Soundness and Completeness

- **Soundness:** An inference system is sound if it produces only valid functional dependencies. Every dependency derived from $F$ using the axioms is guaranteed to hold in all legal relation instances satisfying $F$. It never generates false dependencies.
- **Completeness:** An inference system is complete if it can derive every functional dependency that is logically implied by $F$. Repeated application of the three axioms can infer the entire closure set $F^+$. It leaves no valid dependency unprovable.

### 🎯 LQ2 · Proof of Secondary Inference Rules · 05 Marks

> *Section A / B · Probability: High*

**Question.** State and formally prove the Union, Decomposition, and Pseudotransitivity rules using only Armstrong's three primary axioms.

**Answer.**

#### 1. Proof of the Union Rule
**Statement:** If $\alpha \rightarrow \beta$ and $\alpha \rightarrow \gamma$, then $\alpha \rightarrow \beta\gamma$.

**Proof:**
1. Given $\alpha \rightarrow \beta$, apply Augmentation by adding $\alpha$ to both sides:
$$
\alpha\alpha \rightarrow \alpha\beta \implies \alpha \rightarrow \alpha\beta
$$
2. Given $\alpha \rightarrow \gamma$, apply Augmentation by adding $\beta$ to both sides:
$$
\alpha\beta \rightarrow \beta\gamma
$$
3. By Transitivity on $\alpha \rightarrow \alpha\beta$ and $\alpha\beta \rightarrow \beta\gamma$:
$$
\alpha \rightarrow \beta\gamma
$$
$\blacksquare$

#### 2. Proof of the Decomposition Rule
**Statement:** If $\alpha \rightarrow \beta\gamma$, then $\alpha \rightarrow \beta$ and $\alpha \rightarrow \gamma$.

**Proof:**
1. Since $\beta \subseteq \beta\gamma$, by Reflexivity:
$$
\beta\gamma \rightarrow \beta
$$
2. Given $\alpha \rightarrow \beta\gamma$, apply Transitivity with $\beta\gamma \rightarrow \beta$:
$$
\alpha \rightarrow \beta
$$
3. Similarly, since $\gamma \subseteq \beta\gamma$, by Reflexivity $\beta\gamma \rightarrow \gamma$. Applying Transitivity with $\alpha \rightarrow \beta\gamma$ gives:
$$
\alpha \rightarrow \gamma
$$
$\blacksquare$

#### 3. Proof of the Pseudotransitivity Rule
**Statement:** If $\alpha \rightarrow \beta$ and $\gamma\beta \rightarrow \delta$, then $\alpha\gamma \rightarrow \delta$.

**Proof:**
1. Given $\alpha \rightarrow \beta$, apply Augmentation by adding $\gamma$ to both sides:
$$
\alpha\gamma \rightarrow \gamma\beta
$$
2. Given $\gamma\beta \rightarrow \delta$, apply Transitivity with $\alpha\gamma \rightarrow \gamma\beta$:
$$
\alpha\gamma \rightarrow \delta
$$
$\blacksquare$

## ⚡ Exam Tips & Common Mistakes

- **Decomposition works only on the RHS:** If $AB \rightarrow C$, you cannot decompose the left-hand side into $A \rightarrow C$ or $B \rightarrow C$.
- **Union requires identical determinants:** To merge right-hand sides, both dependencies must share the exact same left-hand side ($A \rightarrow B$ and $A \rightarrow C \implies A \rightarrow BC$).
- **Writing formal proofs:** Always cite the specific primary axiom used in each step (Augmentation, Reflexivity, or Transitivity).
