This directory provides the **Compact Edition** of the ECE 2215 Boss Notes for **Database Systems** in the Department of Electrical and Computer Engineering (ECE) at **RUET**.

Every note in this folder is engineered for **fast, high-retention revision** and **maximum exam marks**:
- **Zero Fluff:** Removed filler headings, rambling analogies, and decorative ASCII box art.
- **Blended Definitions:** Key terms are defined directly inside the core theory using bold lead-in tags (`**[Term]:** [Definition]`).
- **100% Standalone Golden Questions:** Every past semester final question and class test question is quoted verbatim from original papers and paired with a complete, mark-calibrated exam-style answer written inline. Zero pointers or back-references.
- **Strict Visual & Technical Accuracy:** Includes verified diagrams, schemas, and comparison tables calibrated to official course slides and Silberschatz 7th edition.

## 🧭 Structure of Every Compact Note

Every subtopic note follows a consistent, compact layout designed for rapid study:

1. **YAML Frontmatter & Navigation Bar:** Line 1 carries frontmatter (`title` and `tags`). The top navigation bar links to the previous note, the master index, and the next note.
2. **Subtopic Header Block:** States the parent topic, priority tier (`🔴` High, `🟠` Medium, `🟡` Medium, `🟢` Low, `⭐` Unasked), exact past exam mark weight, and source citations.
3. **Core Theory with Blended Definitions:** Clear, concise explanations using short sentences, Markdown comparison tables, and diagram embeds. Key terms are defined right where they appear.
4. **🏆 Golden Questions (Past Exam Archive) / 🔮 Likely Questions:**
   - Quotes verbatim question text from past papers, preserving original formatting and notes.
   - Provides complete, standalone, mark-calibrated exam-style answers written directly inline.
   - Merges identical questions across years into single blocks with concise variant notes.
   - For unasked foundational topics (`⭐`), includes high-probability Likely Questions with complete inline answers.
5. **⚡ Exam Tips & Common Mistakes:** Bullet points highlighting common exam pitfalls, notation traps, and time-saving techniques.
6. **🔗 Related Topics & Closing Navigation Bar:** Cross-references related concepts and closes with the navigation chain.

1. **Start with the [Master Index (`00_Index.md`)](00_Index.md):** Choose the study triage path that matches your remaining prep time (**7+ Days**, **3 Days**, or **1 Night**).
