# T08.7: Testing 2NF from a Functional Dependency Set

> **Topic:** T08 · Normalization & Functional Dependencies | **Priority:** 🟢 Core | **Exam Frequency:** 1/7 finals · 4 marks (2021 Q.5(c))
> **Sources:** Silberschatz 7e Ch. 7 (§7.3.4) · Lecture Deck 06 (Slides 31–36) · Raidah Class Notes (pp. 20, 22)

---

## Testing 2NF: Conditions and Mechanics

**Second Normal Form (2NF):** A relation schema $R$ is in 2NF if it is in 1NF and every non-prime attribute is fully functionally dependent on every candidate key.

**Partial Dependency:** A functional dependency where a non-prime attribute depends on a proper subset of a composite candidate key.

**Prime Attribute:** An attribute that belongs to at least one candidate key of the relation.

**Non-Prime Attribute:** An attribute that does not belong to any candidate key of the relation.

### Necessary Conditions for a 2NF Violation

A 1NF relation violates 2NF if and only if **both** conditions hold simultaneously:
1. The relation has a **composite candidate key** (two or more attributes).
2. A **proper subset** of that composite candidate key functionally determines a **non-prime attribute**.

**Automatic 2NF Satisfactions:**
- If every candidate key is a single attribute, partial dependencies are impossible. The relation is automatically in 2NF.
- If all attributes are prime, there are zero non-prime attributes to be partially dependent. The relation is automatically in 2NF.

---

## 4-Step 2NF Testing Procedure

1. **Find All Candidate Keys:** Compute closures using the L/R/M/N method to identify all minimal superkeys.
2. **Classify Attributes:** Partition attributes into $\text{Prime}(R) = \bigcup CK_i$ and $\text{NonPrime}(R) = R - \text{Prime}(R)$.
3. **Inspect Every Functional Dependency:** For each FD $X \rightarrow Y$:
   - If $Y \subseteq \text{Prime}(R)$, it satisfies 2NF.
   - If $X$ is a superkey, it is a full dependency and satisfies 2NF.
   - If $X \subset CK$ (proper subset) and $Y \subseteq \text{NonPrime}(R)$, it is a **partial dependency** and violates 2NF.
4. **Decompose into 2NF Relations:**
   - Create relation $R_1(X, Y)$ with primary key $X$.
   - Create relation $R_2(R - Y)$ keeping $X$ as a foreign key.
   - Verify lossless join: $(R_1 \cap R_2) = X$, which is the primary key of $R_1$.

### Lecture Walkthrough Drill (Deck 06 Slides 35–36)

Consider $R(A, B, C, D, E, F)$ with $FD = \{A \rightarrow B, C \rightarrow F, EC \rightarrow D, E \rightarrow A\}$.

1. **Find Candidate Keys:**  
   Attributes $C, E$ never appear on any RHS. $(CE)^+ = \{A, B, C, D, E, F\} = R$.  
   Unique Candidate Key: $\{CE\}$.
2. **Classify Attributes:**  
   Prime: $\{C, E\}$. Non-Prime: $\{A, B, D, F\}$.
3. **Analyze Dependencies:**  
   - $EC \rightarrow D$: $EC$ is the candidate key (full dependency, passes 2NF).
   - $C \rightarrow F$: $C \subset CE$ determines non-prime $F$ (**partial dependency, violates 2NF**).
   - $E \rightarrow A$: $E \subset CE$ determines non-prime $A$ (**partial dependency, violates 2NF**).
   - $A \rightarrow B$: Transitive chain ($E \rightarrow A \rightarrow B$).
4. **2NF Decomposition:**  
   - From $C \rightarrow F$: $R_1(\underline{C}, F)$ with PK $C$.
   - From $E \rightarrow A, A \rightarrow B$: $R_2(\underline{E}, A, B)$ with PK $E$.
   - From $EC \rightarrow D$: $R_3(\underline{C, E}, D)$ with PK $(C, E)$.  
   All sub-relations are now in 2NF.

## 🏆 Golden Questions (Past Exam Archive)

### 🎯 GQ1 · 2021 Q.5(c) · Testing and Converting Relation to 2NF · 04 Marks

> *Section B · CLO1 · Asked in: 2021*

**Question.** Given a relation R (A, B, C, D) and functional dependency at FD = { AB $\to$ CD, B $\to$ C }. Determine whether the given R is in 2NF? If not, convert it into 2NF.

*(Note: "functional dependency at FD" printed verbatim from original question paper)*

**Answer.**

#### 1. Determine Candidate Key and Attribute Types

Given relation $R(A, B, C, D)$ and functional dependencies:
$$
FD = \{AB \rightarrow CD, B \rightarrow C\}
$$

- Attribute $A$ never appears on the right-hand side of any dependency. Thus, every candidate key must contain $A$.
- Compute closure of $AB$:
$$
AB^+ = \{A, B, C, D\}
$$
- Test proper subsets:
  - $A^+ = \{A\}$
  - $B^+ = \{B, C\}$  
  Neither subset is a superkey. Therefore, $AB$ is minimal.

$$
\text{Candidate Key} = \{AB\}
$$
$$
\text{Prime Attributes} = \{A, B\}
$$
$$
\text{Non-Prime Attributes} = \{C, D\}
$$

#### 2. Test for Second Normal Form (2NF)

A relation is in 2NF if it is in 1NF and no non-prime attribute depends on a proper subset of any candidate key.

Examine the dependencies:
1. $AB \rightarrow CD$: The determinant $AB$ is the complete candidate key. This is a **full functional dependency**.
2. $B \rightarrow C$: The determinant $B$ is a proper subset of candidate key $AB$, and $C$ is a non-prime attribute. This is a **partial functional dependency**.

Because a partial dependency exists ($B \rightarrow C$), **the relation $R$ is NOT in 2NF**.

#### 3. Conversion to 2NF

To achieve 2NF, we decompose $R$ by isolating the partial dependency into its own relation:

1. Create a relation for the partial dependency:
$$
R_1(B, C) \quad \text{with } FD_1 = \{B \rightarrow C\}
$$
$$
\text{PK of } R_1 = B
$$

2. Remove the determined attribute $C$ from the original relation:
$$
R_2(A, B, D) \quad \text{with } FD_2 = \{AB \rightarrow D\}
$$
$$
\text{PK of } R_2 = AB
$$

**Verification:**
- In $R_1(B, C)$, the candidate key is $B$. The non-prime attribute $C$ depends on the entire key. $R_1$ is in 2NF.
- In $R_2(A, B, D)$, the candidate key is $AB$. The non-prime attribute $D$ depends on the full key $AB$. $R_2$ is in 2NF.
- Lossless join: $R_1 \cap R_2 = \{B\}$, which is the primary key of $R_1$. Thus, the decomposition is lossless.

$$
\boxed{\text{Decomposed 2NF Relations: } R_1(B, C) \text{ and } R_2(A, B, D)}
$$

---

## ⚡ Exam Tips & Common Mistakes

- **Do not discard determinant from base table:** When removing partial dependency $B \rightarrow C$ from $R(A, B, C, D)$, remove only $C$. Attribute $B$ must remain in $R_2(A, B, D)$ to preserve the primary key $AB$ and allow a lossless natural join.
- **Transitive vs. Partial confusion:** An FD like $D \rightarrow E$ where $D$ is non-prime is a transitive dependency (3NF issue), not a partial dependency. A partial dependency requires the determinant to be a proper subset of a candidate key.
