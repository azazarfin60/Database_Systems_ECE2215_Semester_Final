## Vault Statistics & Curriculum Evolution

- **Total Examination Papers:** 7 Semester Finals + 4 Class Tests
- **Total Question Items:** 148 Final sub-questions + 26 CT parts = **174 Question Parts**
- **Total Printed Marks:** 637 Final marks + 80 CT marks = **717 Printed Marks**
- **Diagrams:** 21 Generated diagrams + 1 Question Paper diagram mirrored in local `diagrams/` folder

### Curriculum Eras at RUET
1. **Pre-OBE (2017–2020):** 72 Marks per paper, 3 hours. Strict Section A (Intro, ER, Relational Algebra, SQL) and Section B (Normalization, Transactions, Concurrency, Recovery, Hashing).
2. **Transitional OBE (2021):** 72 Marks per paper, 3 hours. Introduction of Course Learning Outcomes (CLO1–CLO4). Mixed section content.
3. **Modern OBE (2023–2024):** 60 Marks per paper, 3 hours. Structured with CLO/CO mappings. Shift toward modern topics (RAID, Triggers, Stored Procedures, Views, Outer Joins, SQL Injection).
